Create micro services using dot net core web api
1- Client Service     (running port - 5001)
2- Api Gateway (YARP) (running port - 5000)
3- Product Service    (running port - 5002)
4- Inventory Service  (running port - 5003)

Swagger URLs:
=============
http://localhost:5001/swagger
http://localhost:5000/swagger
http://localhost:5002/swagger
http://localhost:5003/swagger

URLs:
=============
http://localhost:5000/api/products/* or http://localhost:5000/api/inventory/*
http://localhost:5002/api/products/*
http://localhost:5003/api/inventory/*

Authentication Flow
===================
	POST /api/auth/login
			│
			▼
	ClientService :5001
			│
			│ Generate JWT
			▼
	JWT Token
			│
			▼
	Client
			│
			│ Authorization: Bearer JWT
			▼
	YARP :5000
			│
			│ Validate JWT
			▼
	ProductService :5002
			│
			│ Validate JWT
			▼
	InventoryService :5003
			│
			│ Validate JWT
			▼
	    Response
